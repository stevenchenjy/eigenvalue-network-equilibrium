# Local exploratory outputs

Runs generate data/<run-id>/ (summary, trajectories and input metadata), figures/<run-id>/ (labeled PNGs) and logs/<run-id>/ (configuration, receipt and provenance). These artifacts are Git-ignored and remain unapproved for assessed use.

Keep all three folders together if retaining a run. Manifests include actual commands, local paths, runtime versions, source fingerprints and artifact hashes. Inspect those records before deliberate external sharing. Existing run IDs are refused rather than overwritten.

Tests and continuous integration create disposable software-validation outputs. A successful check does not constitute an independently produced mathematical result or instructor approval.
